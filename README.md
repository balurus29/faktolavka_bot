# «Фактолавка» — автоканал с интересными фактами в Telegram

Бот сам берёт интересные факты из Википедии, переписывает их в живой пост через бесплатную нейросеть, подбирает фото и видео и публикует в канал 4 раза в день. Иногда добавляет викторину по теме поста — это сильно поднимает вовлечённость.

Всё работает **бесплатно** и **без своего сервера**: бот запускается по расписанию на GitHub.

| Что | Сервис | Цена |
|---|---|---|
| Где работает бот | GitHub Actions | бесплатно |
| Факты | Википедия (избранные и хорошие статьи, «В этот день») | бесплатно |
| Тексты постов | GigaChat (работает в России), Gemini или Groq | бесплатный тариф |
| Фото | картинка из статьи, Pexels, Pixabay, Unsplash, Wikimedia Commons, Openverse, NASA | бесплатно |
| Видео | Pexels, Pixabay | бесплатно |
| Если ничего не нашлось | ИИ-иллюстрация через Pollinations | бесплатно |

Бот определяет тему поста и сам выбирает, где искать картинки: для космоса сначала NASA, для истории и искусства — архивы Wikimedia и Openverse, для природы — фотостоки. Под каждым постом автоматически подписываются источники медиа.

Форматы постов чередуются случайно: одно фото (45%), альбом из 3 фото (20%), видео (20%), фото + видео (15%). Проценты меняются в начале `bot.py`.

## Запуск за 30–40 минут

### 1. Канал и бот
1. В Telegram создайте **публичный** канал (нужна ссылка вида `@имя`).
2. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
3. В канале: Управление → Администраторы → добавьте своего бота, оставьте право «Публикация сообщений».

### 2. Бесплатные ключи
- **GigaChat** (основной для России): зайдите на [developers.sber.ru/studio](https://developers.sber.ru/studio) через Сбер ID → создайте проект **GigaChat API** (для физлиц) → откройте настройки API → **Получить ключ** → скопируйте **Authorization key**. Бесплатно даётся пакет токенов на 12 месяцев, его с запасом хватает на 4 поста в день.
- **Groq** (запасной): [console.groq.com/keys](https://console.groq.com/keys), если регистрация пройдёт.
- **Gemini**: официально недоступен в России, можно не подключать.
- **Pexels**: [pexels.com/api](https://www.pexels.com/api/) → зарегистрироваться → ключ.
- **Pixabay**: зарегистрируйтесь на [pixabay.com](https://pixabay.com), ключ появится на странице [pixabay.com/api/docs](https://pixabay.com/api/docs/).
- **Unsplash**: [unsplash.com/developers](https://unsplash.com/developers) → New Application → скопируйте **Access Key**.

Wikimedia Commons, Openverse, NASA и Pollinations работают без ключей. Фотостоки необязательны: каких ключей нет, те источники бот просто пропускает. Но чем больше ключей, тем шире выбор картинок и видео.

> Достаточно одного ключа нейросети. Если их несколько, бот пробует по очереди: GigaChat → Gemini → Groq. Если не ответит ни одна, опубликует выдержку из статьи без переработки.

### 3. GitHub
1. Зарегистрируйтесь на [github.com](https://github.com) → **New repository** → имя любое → **Public** (у публичных репозиториев безлимитные минуты; ключи всё равно остаются скрытыми).
2. **Add file → Upload files** → перетащите **всю папку проекта целиком**, включая скрытую папку `.github`. Проверьте, что в репозитории появился файл `.github/workflows/autopost.yml`.
3. **Settings → Secrets and variables → Actions → New repository secret**, добавьте:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHANNEL` | `@имя_вашего_канала` |
| `GIGACHAT_AUTH_KEY` | Authorization key GigaChat |
| `GEMINI_API_KEY` | ключ Gemini (необязательно) |
| `GROQ_API_KEY` | ключ Groq |
| `PEXELS_API_KEY` | ключ Pexels |
| `PIXABAY_API_KEY` | ключ Pixabay |
| `UNSPLASH_ACCESS_KEY` | Access Key из Unsplash |

4. Там же, вкладка **Variables** (необязательно): `CHANNEL_SIGNATURE` = `👉 @имя_канала` — подпись под каждым постом.
5. **Settings → Actions → General → Workflow permissions** → выберите **Read and write permissions** → Save. Без этого бот не запомнит, что уже публиковал, и начнёт повторяться.

### 4. Первый пост
**Actions → Автопостинг → Run workflow**. Через 1–2 минуты пост появится в канале. Если нет — откройте запуск и посмотрите ошибку в логе.

Дальше бот публикует сам: 09:07, 13:13, 18:21 и 21:09 по Москве. GitHub иногда задерживает запуск на 5–30 минут — это нормально.

## Настройка

- **Время и количество постов** — строки `cron` в `.github/workflows/autopost.yml` (время в UTC: московское минус 3 часа).
- **Доли форматов, частота викторин** — `POST_TYPE_WEIGHTS`, `QUIZ_CHANCE`, `ONTHISDAY_CHANCE` в начале `bot.py`.
- **Стиль текста** — блок `PROMPT` в `bot.py`.
- **Запрещённые темы** — `STOP_WORDS` (по умолчанию отсекаются войны, теракты, катастрофы: для развлекательного канала они портят атмосферу).
- **Порядок источников картинок по темам** — `PHOTO_ORDER` в `media.py`.
- **ИИ-иллюстрации** — выключаются переменной `AI_IMAGE_FALLBACK` = `0` (вкладка Variables).
- **Модель GigaChat** — переменная `GIGACHAT_MODEL` (по умолчанию `GigaChat-2-Max`, самая умная; когда её бесплатные токены кончатся, бот сам перейдёт на `GigaChat-2`).
- **Модель Gemini** — переменная `GEMINI_MODEL` (по умолчанию `gemini-flash-latest`). Если Google переименует модели, впишите актуальное имя из AI Studio.

Если обе нейросети недоступны, бот всё равно опубликует пост — выдержку из статьи без переработки.

## Как на этом зарабатывать

Честно: канал сам по себе денег не приносит, приносит **аудитория**. Автопостинг решает контент, а подписчиков придётся привлекать — без бюджета это делается вашим временем.

**Рост с нулём бюджета**
- Взаимопиар с каналами похожего размера (ищите в каталогах вроде TGStat по теме «познавательное»).
- Папки каналов (shared folders) — объединяйтесь с 5–10 соседними каналами.
- Ролики с фактами в YouTube Shorts / TikTok / VK Клипах со ссылкой на канал. Видео из Pexels + текст поста — готовый материал.
- Первые 50–100 подписчиков — друзья и свои соцсети; пустой канал не подписывают.

**Монетизация**
1. **Официальная реклама Telegram.** Telegram отдаёт владельцам каналов 50% выручки от показанной в них рекламы, выплаты — в криптовалюте TON через Fragment. Порог для подключения — около 1000 подписчиков. Включается в настройках канала, раздел «Монетизация». Суммы на старте небольшие.
2. **Продажа рекламы напрямую** — основной доход познавательных каналов. Ставите ссылку «по рекламе — @вы» в описание канала, регистрируете канал на биржах (Telega.in, TGStat). Начинают покупать примерно от 1–3 тыс. подписчиков.
3. **Партнёрские ссылки** — книги, курсы, настолки по теме постов.

Учтите: Telegram и рекламодатели плохо относятся к накрутке. Живые подписчики и реальные просмотры важнее цифр.

## Проверка у себя на компьютере (по желанию)
```
pip install -r requirements.txt
# задайте переменные окружения из таблицы выше, затем:
python bot.py --dry-run          # покажет пост, ничего не опубликует
python bot.py --type video       # реальная публикация видео-поста
```
